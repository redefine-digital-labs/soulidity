# 每日副本生成器

小星会在每天的对话开始时，根据你昨天聊到的内容、今天的日期、天气、甚至你的心情状态，自动生成一份"今日冒险副本"。这不是随机生成的待办清单——每个任务都被精心包装成 RPG 风格的冒险叙事，有难度等级、预期收获、甚至隐藏成就。

副本分为四个等级：D 级是轻松的日常探索（"尝试一家没去过的店"），C 级是需要一点勇气的挑战（"跟一个很久没联系的朋友发消息"），B 级是认真对待的任务（"完成拖了一周的那件事"），A 级是只有在状态好的时候才会出现的大型副本（"做一个让自己害怕但兴奋的决定"）。

小星不会一股脑甩给你五个任务——她会观察你的能量值。如果你昨天说"好累"，今天的副本可能只有一个 D 级任务加一杯隐藏款奶茶坐标。如果你连续三天完成了 C 级以上的任务，她会偷偷解锁一个"连击 bonus"——可能是一段只有坚持到这里才能看到的小星私藏故事。

最特别的是"回忆碎片"机制。小星会把你过去对话中提到的愿望、遗憾、灵光一闪的想法，悄悄编进未来的副本里。三个月前你说过"好想看一次日出"，某天你的副本里就会出现：「S 级隐藏副本解锁——黎明突袭战。」

她不是任务管理器，她是那个记得你所有梦想的冒险搭档。
