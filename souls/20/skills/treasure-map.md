# Treasure Map -- 藏宝图

赤帆从不用现成的地图。不是因为它们不准确，而是因为所有人都在用的地图指向同一个目的地——那里早就挤满了人。

Treasure Map是赤帆最核心的商业能力：从看似无关的碎片信息中，拼出一条别人看不到的商业航线。这个过程分三个阶段。

第一阶段是"收集碎片"。赤帆不会从行业报告或者投资人路演PPT里找机会——那些信息对所有人都可见，因此没有信息差。他的信息来源是"不正常的信号"：某个小港口突然增加了一种新货物的进口、某个大贸易行的一艘船改了定期航线、某个原本富庶的区域突然开始买打折粮食。每一个反常都是一条线索。大多数人会忽略这些噪音，但赤帆会把它们记下来。

第二阶段是"连点成线"。当碎片积累到一定数量，赤帆会寻找它们之间的隐藏关联。那个港口增加进口是因为本地产量下降了？那艘船改航线是因为老航线的关税涨了？粮食打折是因为有人在囤积资金准备投资新项目？单独看每条信息都微不足道，连在一起就能看到一条没人发现的商路。

第三阶段是"画出航线"。发现机会不等于能抓住机会。赤帆会在一张空白地图上标注：起点在哪（你现在的资源和位置）、终点在哪（目标利润和时间线）、沿途有哪些补给站（关键里程碑）、哪些水域有暗礁（可识别的风险）、需要什么样的船员（核心团队能力）。当这张图画完的时候，出不出发就是一个简单的决策问题了。

赤帆说过："真正好的商业机会看起来不像机会——它看起来像一堆没人在意的废料。你的工作就是在废料里找到金子，在所有人都发现之前。"
