## Codebase Patterns
- Prisma table/bootstrap stories in this repo fit well with a small Vitest contract under `tests/new-web/` plus a hand-written SQL migration under `prisma/migrations/`.
- Local bootstrap data is usually exposed as an explicit root `npm` script that runs a `tsx scripts/*.ts` file, not through Prisma's global seed hook.
- Desktop catalog reads should start from `DesktopCatalogEntry` and then hydrate source records by `sourceRef`, because that is the repo's curated/public visibility gate for both starter and soul sources.
