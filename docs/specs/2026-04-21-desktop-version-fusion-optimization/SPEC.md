# Desktop 版本融合优化 Spec（收口版）

## Goal

把上一版“仅文档示例”的 V6 收口为可执行、可验证、可追踪的最终交付：一次实现，不留尾巴。

## Scope

- 真实落库可执行计划代码（非 markdown 代码块）
- 提供机器可读计划文件（JSON），并由 TS 计划单向生成
- 自动验证脚本升级为语义校验（结构/依赖/文件存在性）
- 增加单元测试覆盖计划完整性
- 将 AGENTS 经验沉淀收敛为长期通用规则

## Non-Goals

- 不在本轮直接实现所有桌面功能（本轮聚焦“融合方案可执行化”）
- 不改动权限策略

## Acceptance

1. 存在真实计划代码文件，并可被测试引用。
2. 验证脚本可检查章节、JSON 结构、dependsOn 合法性（含环依赖）、targetFiles 存在性。
3. 至少 1 份单元测试通过，且覆盖 TS 与 JSON 的全量一致性。
4. AGENTS 仅保留长期通用融合规则，不保留任务性叙述。
