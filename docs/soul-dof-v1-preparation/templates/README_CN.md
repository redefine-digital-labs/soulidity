# 证据模板使用规则

复制到本次实际候选的证据目录，填准确ID/commit/environment/整数金额/读回/结果，再链接原研发或旅程记录。空值、Not run和Planned保留到实际验证，不视为通过。不要填私钥、助记词、token或私密素材；不要把模板作为真实部署清单。

release-manifest：组合候选与部署；journey-execution：37步每步结果；permission-register：真实Cap/Owner/锁；reconciliation-ledger：逐笔资金；security-findings：审查发现与复验；monitoring-register：真实告警及演练；fixture-manifest：演示与待实测素材；sprint-plan：沿既有研发记录排迭代。
