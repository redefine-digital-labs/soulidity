## 第一批质量门

- 结构检查：8/8 均包含任务范围、最终结论、关键决策、历史路径或证据、验证结果、风险/未完成项、恢复动作和来源追踪。
- 映射检查：8/8 的 thread ID、source/archive 字节数和 SHA-256 与 manifest 一致。
- 来源检查：8/8 的脱敏导出 SHA-256 正确，所有代表性消息 SHA-256 均存在于对应导出。
- 安全检查：相对链接、文件大小、敏感材料扫描和 `git diff --check` 通过。
- 内容检查：纪要将审计时快照、计划、实际完成和后续 Git 变化分开，不把历史 gate 值宣称为当前状态。

## 使用规则

- 历史判断必须重新对照当前源码、测试和链上读回，尤其不要把旧的 gate 状态当成当前状态。
- 文件路径可能只存在于历史提交或旧 worktree；以纪要列出的提交为定位入口。
- 这些纪要可以支持工程恢复和决策回溯，但不能恢复完整对话、工具输出或逐步取证过程。
