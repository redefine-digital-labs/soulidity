# Soulidity Foundation

## 使命

Soulidity Foundation 负责将 Labs 研发的产品推向市场，建立品牌、社区和生态合作关系，并管理项目的融资与代币发行。

---

## 核心职责

| 领域 | 具体工作 |
|------|---------|
| **对外合作 & BD** | Walrus Grant 申请、Eve 合作、Sui 生态关系 |
| **融资** | 投资人沟通、Deck 更新、融资轮管理 |
| **品牌 & 传播** | 项目叙事、对外形象、Twitter / Discord 内容 |
| **发行 & 运营** | Collection 发行策略、用户增长、社区管理 |
| **团队协调** | Foundation 内部合伙人分工、与 Labs 的跨部门对齐 |
